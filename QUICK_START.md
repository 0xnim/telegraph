# 🚀 Quick Start Guide - Telegraph Mod

## Installation
1. Install Fabric Loader for Minecraft 1.21+
2. Place mod JAR in `mods` folder
3. Launch Minecraft

## First Steps (30 seconds)

### 1. Get a Map
```
Get any filled map in your hotbar (slots 0-8)
```

### 2. Open Interface
```
Press M key
```

### 3. See Your Channels
```
Left panel = your maps (channels)
Right panel = messages on selected channel
```

**That's it! You're now tracking map messages!**

## Learning Carnite (5 minutes)

### Step 1: Enable Carnite
```
1. Click "Advanced" button
2. Click "Protocol: Telegraph" to cycle
3. Now shows "Protocol: Carnite"
4. Click "Done"
```

### Step 2: Open Composer
```
1. Click "Compose" button
2. Carnite Composer opens (colorful UI)
```

### Step 3: Activate Learning Mode
```
1. Type anything (or use templates)
   Example: ~rd| ;
   
2. Click "Learn" button (bottom left)
3. Green panel appears!
```

### Step 4: Learn by Hovering
```
Move mouse over ANY part:
- Hover "~" → see "Plural/About"
- Hover "rd" → see "abbreviation for: raiders"
- Hover "|" → see "Agent/Individual marker"
- Hover ";" → see "My civilization"
```

### Step 5: See Translation
```
1. Click "Expand" button (instead of Learn)
2. See full English translation
3. See word-by-word breakdown
```

## Practice Messages

### Beginner Messages
```
~rd| ;           → "Raiders at my civ" (RED banner)
2bld| CN:        → "2 builders to Carnation" (LIGHT BLUE banner)
.dmd CN ; trd    → "Traded 1 stack diamonds to CN" (LIGHT GRAY banner)
```

### Intermediate Messages
```
.brd,32irn ; _:  → "Offering bread & iron, what for?" (YELLOW banner)
_ CN atk         → "Who is attacking Carnation?" (BLUE banner)
^ y              → "Response: yes" (WHITE banner)
```

### Advanced Messages
```
2.5dmd CN: EG&DR; trd    → Complex trade
-acpt CN: ;              → "CN, we do not accept"
~rd| SF DR; atk          → Multi-civ military coordination
```

## Cheat Sheet

### Essential Symbols
```
|  = individual/agent     "bld|" = a builder
:  = your civ            "CN:" = to Carnation
;  = my civ              ";" = us/we
,  = property of         "CN,dp|" = Carnation's diplomat
&  = and                 "bld|&mn|" = builder and miner
.  = stack (64)          ".dmd" = 64 diamonds
_  = question            "_ atk" = who is attacking?
^  = response            "^ y" = yes
~  = plural/about        "~5" = about 5
-  = not/negate          "-acpt" = do not accept
```

### Common Abbreviations
```
rd = raid/raider      dmd = diamond       atk = attack
bld = builder         irn = iron          trd = trade
mn = miner            brd = bread         ally = ally
dp = diplomat         gpdr = gunpowder    mv = move
smth = blacksmith     fd = food           srd = surrender
lib = librarian       ench = enchant      wtd = wanted
```

### Banner Colors
```
WHITE      = Present happening now
LIGHT GRAY = Past (already happened)
GRAY       = Future (will happen)
PINK       = Conditional (might)
RED        = URGENT (emergency!)
LIGHT BLUE = Request/Command
BLACK      = Decision made
BLUE       = Question (yes/no)
YELLOW     = Trade offer
PURPLE     = Goal/Objective
```

## Tips

### 💡 Best Practices
- Start with templates
- Use Learning Mode for everything at first
- Always click "Validate" before copying
- Use "Expand" to double-check translation
- Keep messages under 32 characters for readability

### 🎯 Learning Strategy
1. **Day 1:** Learn 4 symbols (|, :, ;, ,)
2. **Day 2:** Learn 5 abbreviations (rd, atk, bld, dmd, irn)
3. **Day 3:** Learn banner colors (tenses)
4. **Day 4:** Practice simple statements
5. **Day 5:** Try questions and trades
6. **Day 6:** Master word order (Od Oi S V)
7. **Day 7:** Compose without help!

### ⚡ Keyboard Shortcuts
```
M          = Open map interface
ESC        = Close any screen
Tab        = (in text field) move focus
Enter      = (in text field) confirm
Click      = Select channel
```

## Troubleshooting

### "I don't see messages"
- Ensure filled map is in hotbar (slots 0-8)
- Ensure banners are placed on the map area
- Right-click banner with map to register
- Check Messages tab (not Raw)

### "Learning Mode not showing colors"
- Type a message first
- Click "Learn" button
- Look for green border around panel
- Try clicking "Learn" again to toggle

### "Hover tooltips not appearing"
- Move mouse slowly
- Hover directly over colored text
- Wait 0.5 seconds
- Ensure Learning Mode is active (green border)

### "Notifications not working"
- Check Channel Settings → Notifications: ON
- Check Notification Level: ALL or IMPORTANT_ONLY
- Ensure map is in hotbar
- Wait for banner changes (not instant)
