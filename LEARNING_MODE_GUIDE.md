# 🎓 Carnite Learning Mode - Quick Guide

## What is Learning Mode?

Learning Mode is an **interactive educational feature** in the Carnite Message Composer that helps you understand every part of a Carnite message by breaking it down piece-by-piece.

## How to Use

1. **Open Carnite Composer**
   - Press `M` key → Select channel → Click "Compose"
   - Composer opens automatically if using Carnite Protocol

2. **Type a message** (or use templates)
   - Example: `~rd| ;` or `2.5dmd CN: ; trd`

3. **Click "Learn" button** (bottom left)
   - Message parts become **color-coded**
   - Green border appears around learning panel

4. **Hover over ANY part** to see:
   - ✅ What it means
   - ✅ Expanded full word
   - ✅ Grammatical function
   - ✅ How it's used

## Color Coding System

| Color | Meaning | Examples |
|-------|---------|----------|
| 🔵 **Cyan** | Entities (civs, players) | `CN`, `DR`, `;`, `:` |
| 🟢 **Green** | Quantities (numbers, stacks) | `2`, `5`, `32` |
| 🟡 **Yellow** | Abbreviations | `dmd`, `rd`, `bld`, `atk` |
| 🟣 **Purple** | Modifiers (plural, negation) | `~`, `-` |
| 🟠 **Orange** | Connectors | `,`, `&` |
| 🔴 **Magenta** | Questions | `_` |
| 🩷 **Pink** | Responses | `^` |
| ⚪ **Gray** | Symbols | `\|`, `.` |
| ⚪ **White** | Regular words | other text |

## Example Session

### Input Message
```
2bld|5 CN: ; atk
```

### What You See in Learning Mode

**Color-coded breakdown:**
- `2` - 🟢 Green (quantity)
- `bld` - 🟡 Yellow (abbreviation: "builder")
- `|` - ⚪ Gray (agent marker)
- `5` - 🟢 Green (level)
- `CN` - 🔵 Cyan (Carnation civilization)
- `:` - 🔵 Cyan (addressing them)
- `;` - 🔵 Cyan (my civilization)
- `atk` - 🟡 Yellow (abbreviation: "attack")

**When you hover over `bld`:**
```
'bld' → builders
Abbreviation for: builder
```

**When you hover over `|`:**
```
'|' → |
Individual/Player marker - indicates this is a specific person
```

**Structure Panel Shows:**
```
Message Structure:
• Type: STATEMENT
• Word Order: Od Oi S V (Object, Location/To, Who, Action)
• Contains: Subject (who)
• Contains: Verb (action)
```

## Common Learning Scenarios

### Learning Symbols
**Try:** `;`
- Hover: "My civilization - refers to speaker's civ (we/us)"
- Color: Cyan (Entity)

### Learning Stack Notation
**Try:** `2.5dmd`
- Hover over `.`: "Stack of 64 items"
- Hover over `2`: "Number: 2"
- Hover over `5dmd`: "5 diamonds"
- Expand shows: "133 diamonds (2 stacks + 5)"

### Learning Trade Format
**Try:** `.brd ; _:`
- Yellow banner (trade)
- Each part explained separately
- Structure shows: "Type: TRADE OFFER"

### Learning Questions
**Try:** `_ CN atk`
- Blue banner (question)
- Hover over `_`: "Question blank - what you're asking about"
- Expand shows: "Who is attacking Carnation?"

## Pro Tips

1. **Start Simple**
   - Begin with templates
   - Learn one symbol at a time
   - Build up to complex messages

2. **Use Both Modes**
   - **Learn Mode** = understand structure
   - **Expand Mode** = verify meaning

3. **Practice Common Patterns**
   - `~rd| ;` (raiders at my civ)
   - `2bld| CN:` (sending 2 builders to CN)
   - `_ ; atk` (who is attacking us?)
   - `.dmd ; _:` (offering diamonds for what?)

4. **Legend is Your Friend**
   - Always visible in top-right of learning panel
   - Quick reference for colors
   - No need to memorize

5. **Combine with Validation**
   - Use "Validate" to check for errors
   - Use "Learn" to understand why
   - Use "Expand" to confirm intent

## Learning Progression

### Beginner (Start Here)
1. Learn the 4 basic symbols: `|`, `:`, `;`, `,`
2. Learn 5 common abbreviations: `rd`, `atk`, `bld`, `dmd`, `irn`
3. Understand banner colors (tense)
4. Practice simple statements

### Intermediate
1. Learn stack notation: `.`
2. Learn modifiers: `~`, `-`
3. Learn question format: `_`
4. Understand word order: Od Oi S V

### Advanced
1. Learn response chaining: `^`
2. Master trade format with `;` and `:`
3. Use compound expressions with `&`
4. Create multi-part messages

## Troubleshooting

**Q: Colors not showing?**
- Make sure Learning Mode is ON (green border)
- Type a message first
- Click "Learn" again to refresh

**Q: Hover not working?**
- Move mouse slowly over text
- Ensure you're inside the green learning panel
- Wait a moment for tooltip to appear

**Q: Want to see translation?**
- Switch to "Expand" mode instead
- Shows full English translation
- Lists all expansions

**Q: Can I use both modes?**
- No - they toggle between each other
- Learn = interactive hover
- Expand = full translation view
- Choose based on what you need
